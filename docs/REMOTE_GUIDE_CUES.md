# Running Guide Cues

Running-guide rooms use stricter cues than casual live rooms. Remote guidance
should be short, consistent, and early enough for the runner to react safely.

## Core Cues

```text
정지
천천히
직진
왼쪽 조금
오른쪽 조금
앞에 장애물
앞에 사람
앞에 턱
길 좁아짐
좋아요 유지
```

## Speaking Rules

- Use the shortest cue that is still clear.
- Say the cue before the runner reaches the hazard.
- Avoid long explanations during movement.
- Use "정지" when unsure.
- Resume only after the runner confirms readiness.

## App Support

The guide screen uses one-tap cue buttons. Each tap creates a structured cue
event for the live session so the app can keep wording consistent under
pressure without storing free-form speech text. The host screen polls these
events, displays the latest cue, shows recent cue history, and speaks it
through Korean TTS. The supporter screen also shows recent cue history so a
guide can confirm what was sent.
